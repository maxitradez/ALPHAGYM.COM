# Alpha Gym

Alpha Gym website and gym management platform.

## Project structure
- `index.html` — public gym website
- `portal.html` — member portal interface
- `app.html` — gym management interface
- `store.js` — current application data layer
- `app.js` — management interface logic
- `style.css` — shared styles

## Development
The frontend is being prepared for integration with Supabase. Authentication, shared database storage, role-based permissions, and production attendance workflows will be implemented before the system is used with real member information.

## Deployment
The frontend can be hosted as a static site. Do not place Supabase secret keys, service-role keys, passwords, or other private credentials in this repository.
